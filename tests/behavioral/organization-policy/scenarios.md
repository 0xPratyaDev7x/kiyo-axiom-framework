# Organization policy scenario specifications

These are synthetic **expected behavior**, not executed results. Each full case
is NOT_RUN. Bounded source trials, if run, have separate evidence and do not
promote this entire matrix or native enforcement. No real secrets, personal
identities, domains, production access or external probes are needed.

Subject: existing Init preview and Security governance submode plus shared
[configuration](../../../src/kiyo/framework/project-configuration.md),
[resolution](../../../src/kiyo/governance/policy-resolution.md) and
[presets](../../../src/kiyo/governance/presets.md).
Controls: KIYO-CONFIG-001, KIYO-POLICY-001, KIYO-AUTH-001/002/003,
KIYO-SAFE-001, KIYO-DATA-001, KIYO-PROVIDER-001 and KIYO-INIT-001.
Record exact supplied/inspected scope, checks, actual file effects and limits.

when no operation executes.
