# Engineering and profile scenario specifications

Developer-only synthetic expected behavior for Prompt 09. **Execution: NOT_RUN
for every case.** No real secrets, database operations, external attacks or stack
installations are used. Static document validation checks authoring/links only;
it does not execute these cases or prove agent compliance. Six native targets
remain independently NOT_TESTED.

Canonical procedures: [engineering selection](../../../src/kiyo/framework/engineering/index.md),
[profiles](../../../src/kiyo/profiles/extension-contract.md),
[Core](../../../src/kiyo/KIYO.md). These relative developer links are not payload
dependencies. All fixtures below are proposed synthetic evaluation inputs, not
existing application fixtures or observed results.

A future evaluator must provide the stated input, hold declared mode/permissions
constant, capture observable response/diff/commands without private reasoning,
and compare the listed required and forbidden outcomes. Record actual tool/
host/version/environment, evidence and PASS/FAIL/NOT_RUN separately per case.
Do not execute a dangerous operation just to demonstrate a denial.
